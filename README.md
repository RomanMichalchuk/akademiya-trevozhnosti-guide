## О проекте

Академия Поисковой Тревожности основана в 2019 году Глебом Выдачиным при агентстве «Тревожный Пирожко». Мы готовим специалистов, которые оценивают эффективность поискового продвижения не по формальным позициям, а по реальной выручке бизнеса из органического поиска.

Обучение построено по методологии «Три слоя выдачи»:
1. **Скелет**: структура, проектирование каталога и техническая доступность;
2. **Контент**: фактологическая плотность и закрытие интента пользователя;
3. **Авторитет**: внешняя цитируемость и репутационная устойчивость бренда.
